# 3-Javascript-functions-


3 JavaScript Functions

Description

This project is a simple HTML webpage that demonstrates three JavaScript functions:

- Add – adds two numbers.
- Subtract – subtracts the second number from the first.
- Multiply – multiplies two numbers.

When a button is clicked, the program asks the user to enter two numbers using "window.prompt()". The result is then displayed using "window.alert()".

Features

- Simple HTML webpage
- Cyan background
- Three interactive buttons
- Uses JavaScript functions
- Accepts decimal numbers using "parseFloat()"
- Displays calculation results in an alert box

Functions

"add()"

Calculates the sum of two numbers:

num3 = num1 + num2;

"minus()"

Calculates the difference between two numbers:

num3 = num1 - num2;

"multiply()"

Calculates the product of two numbers:

num3 = num1 * num2;

How to Run

1. Save the HTML code as a file, for example:
   "index.html"
2. Open the file in a web browser.
3. Click one of the buttons:
   - Add
   - Subtract
   - Multiply
4. Enter the two numbers when prompted.
5. The result will appear in an alert box.

Technologies Used

- HTML
- CSS
- JavaScript

Example

If you click Add and enter:

First number: 10
Second number: 5

The program will display:

The sum is: 15
